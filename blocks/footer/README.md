# Footer

Loads the site's footer fragment (`<site folder>/footer`, or page metadata `footer`). Sections:

1. Optional **PREA hotline strip**: an icon paragraph, h2, text and button links.
2. A **Family Of Sites** block.
3. **Link columns**: each `h2` starts a column, followed by paragraphs and/or a list.
4. **Bottom bar**: a copyright paragraph and a list of legal links.
