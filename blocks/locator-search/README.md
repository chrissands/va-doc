# Locator Search

| Locator Search |
| --- |
| eyebrow, h2, description |
| link to the form definition (e.g. `/forms/offender-locator.json`) |
| footnote (optional, text and/or link) |

Renders a card with a form built by the form block's `createForm()`. It requires either first and
last name or a 7-digit ID, plus the certification. In the demo it shows a "not connected" result
panel. When placed in the same section as a hero, the hero shows it as its right column.
